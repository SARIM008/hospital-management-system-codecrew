# Team-13 CodeCrew - Frontend Installation Guide

## Hospital Management System (Frontend)

This directory contains the frontend source code for the Software Engineering group project developed by **Team-13 (CodeCrew)**.

The system is a modern, web-based **Hospital Management System**.

The frontend is implemented as a **Single Page Application (SPA)** using the **Vue 3 ecosystem**.

---

## Prerequisites

* Node.js (recommended: latest LTS version)
* npm (comes with Node.js)

---

## Installation

Open a terminal and run:

```bash
cd frontend
npm install
```

This will install all required frontend dependencies.

---

## Running the Development Server

Start the frontend application with:

```bash
cd frontend
npm run dev
```

---

## Accessing the Application

Once the development server starts, open the application in your browser at:

```
http://localhost:5173
```
